# **App Name**: EZBus

## Core Features:

- Route Display: Display available bus routes with details like destination, time, and price.
- Seat Selection: Interactive seat selection with a graphical seat map showing available seats.
- Ticket Display: Display a QR code ticket upon successful purchase.
- Admin Route Management: Admin panel to add and manage bus routes, including destination, time, price and bus seat configuration.
- Bus Configuration: Admin interface to define and customize the seat layout for different bus types.
- AI Price Recommendation: Tool to analyze current and past booking trends to assist the admin user in setting prices that optimize booking rate and revenue.
- QR Code Scanner: Web page and associated features that allow the administrator to scan the ticket QR code using the device's camera to confirm its validity.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to evoke trust and sophistication.
- Background color: Very light lavender (#F0F8FF), almost white, creating a clean and airy feel.
- Accent color: Vibrant Purple (#A020F0) for call-to-action buttons and highlights.
- Font pairing: 'Playfair' (serif) for headings to give a classic and elegant feel, combined with 'PT Sans' (sans-serif) for body text to maintain readability.
- Use simple, outlined icons to represent various elements like destinations, departure times and bus features.
- A clean, grid-based layout with clear separation between sections, and ensure a seamless user experience.
- Smooth transitions and subtle animations to enhance user interaction, such as route details sliding in.
